# 无人机设备基础抢答对决系统

面向中职无人机应用技术专业课堂的答题对决网站。系统支持班级设置、1v1 抢答、擂台连胜挑战、8 强淘汰赛、胜场英雄榜和本地数据保存，适合课堂投屏、复习检测和竞赛式互动。

## 开发工具

- 大模型辅助：DeepSeek 国产大模型，用于梳理课堂需求、生成题库结构、辅助设计交互流程和迭代代码。
- 代码编辑器：TRAE、CodeBuddy，用于整理前端项目、调试页面和维护题库。
- 前端技术：React、JavaScript/JSX、Tailwind CSS、Vite。

## 运行方式

本项目不需要后端服务，也不需要配置大模型 API Key。

### 方式一：直接打开

双击 `index.html`，或用浏览器打开该文件即可运行。项目默认读取同级目录下的 `tailwind.js`、`react.js`、`react-dom.js`、`babel.js`，便于无网络课堂使用。

### 方式二：本地开发预览

1. 安装 Node.js。
2. 在项目目录执行：
   ```bash
   npm install
   npm run dev
   ```
3. 浏览器访问终端中显示的本地地址，默认端口为 `3000`。

## 课堂使用

1. 在首页选择班级和班级人数。
2. 选择 `进入抢答模式 (1v1)`、`擂台连胜挑战` 或 `进入淘汰赛模式`。
3. 学生按学号参与抢答，系统自动计分并保存本机浏览器排行榜。
4. 可在 `查看胜率英雄榜` 中查看或清空当前班级记录。

## 修改题库

当前版本的题库内置在 `index.html` 文件中，变量名为 `RAW_QUESTIONS`。每道题使用 JSON 对象描述，包含题号、题干、选项和正确答案。

题目格式示例：

```js
{
  id: 1,
  question: "遥控系统包括（　　）。",
  options: [
    { letter: "A", text: "遥控器" },
    { letter: "B", text: "接收机" },
    { letter: "C", text: "执行器" }
  ],
  answer: "D"
}
```

添加或修改题库的方法：

1. 用 TRAE、CodeBuddy 或其他代码编辑器打开 `index.html`。
2. 搜索 `const RAW_QUESTIONS = [`。
3. 按照现有 JSON 格式新增、删除或修改题目。
4. 保存后重新打开 `index.html`，或执行 `npm run dev` 预览。

注意：当前版本不支持直接上传 Word 或 PDF 自动同步题库。这个功能可以作为后续扩展，但需要先约定题目文档格式，并增加 Word/PDF 解析库、题目校验和导入预览流程。为了保证课堂使用稳定性，当前开源版本采用“手动维护内置 JSON 题库”的方式。

## 数据说明

排行榜数据保存在浏览器 `localStorage` 中，不上传服务器。更换电脑或清理浏览器数据后，原有记录会消失。
